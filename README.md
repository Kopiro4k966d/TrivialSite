# Trivial Client Site 2.0

Рабочий сайт, API авторизации, лицензии и защищённая загрузка лаунчера.

## Быстрый запуск
1. Установите Node.js 20+ и PostgreSQL.
2. Выполните `database/schema.sql` в вашей базе.
3. Скопируйте `.env.example` в `.env` и задайте `DATABASE_URL` и длинный `SESSION_SECRET`.
4. Выполните `npm install` и `npm start`.
5. Откройте `http://localhost:3000`.

## Публикация клиента
Задайте в окружении:
- `CLIENT_DOWNLOAD_URL` — HTTPS URL приватной/подписанной загрузки JAR;
- `CLIENT_SHA256` — SHA-256 JAR;
- `MINECRAFT_VERSION` и `FABRIC_LOADER_VERSION`.

Без `CLIENT_DOWNLOAD_URL` лаунчер авторизуется и показывает профиль, но запуск клиента намеренно заблокирован — это защищает от запуска пустой/неопубликованной сборки.

## Защищённая загрузка лаунчера
Лаунчер лежит в `storage/launcher/TrivialLauncher.zip`, но `/storage` закрыт. Скачивание идёт только через `/api/download/launcher`, который проверяет токен и активную подписку. В production можно вместо файла задать `LAUNCHER_DOWNLOAD_URL`.

## Роли
Для доступа к `admin-panel.html` измените роль пользователя в БД на `creator` или `admin`.

## Важно
Платёжные ссылки остаются внешними. Автоматическую выдачу ключей после оплаты необходимо подключить webhook-ом конкретного платёжного провайдера; без его API-ключей безопасно реализовать это невозможно.
